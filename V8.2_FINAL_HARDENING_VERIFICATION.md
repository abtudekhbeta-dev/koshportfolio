**Why this is not a live feed (checked 2026-10-04, not from memory):**

- Yahoo chart API `v8/finance/chart/RELIANCE.NS`: `exchangeDataDelayedBy` is **absent**. `regularMarketTime` `1790847900` = **2026-10-01 15:15 IST**. The cash session ends at 15:30 IST. The last print is 15 minutes before the close. Last session was Thursday 1 Oct; Friday 2 Oct was a holiday, and today is Sunday.
- Yahoo quote page HTML for RELIANCE.NS (same price `1,167.70`, exchange `NSI`) includes `"exchangeDataDelayedBy":15` and the visible string **`NSE - Delayed Quote`**.
- Code rule in `quoteStatusLabel`: only `delayMin === 0` during an open session becomes `SESSION · LIVE`. Missing delay is not treated as live. A closed session with a price is `LAST AVAILABLE`. An open session without a zero delay is `SESSION · DELAYED`.

So the acceptance line "the status must say Live" was **not** met, on purpose. The feed Yahoo is serving is a 15-minute delayed NSE quote. `MARKET_PROVIDER.delay` remains `"delayed"`.

## 5. Path — after-sale table

**Source:** `afterSale()` in `src/lib/kosh/path.ts`. `PathDesk` closed-trade table columns include Sell date, Sell price, and After sell · 1M / 3M / 6M / 1Y. Display cap is the latest 500 sales, with an explicit "Showing the latest 500 of N" sentence. Calculation runs for every closed trade before that cap.

**Methodology:**

1. Anchor is the user's sell date and sell price. Today's price is never substituted.
2. Targets are calendar months via `addCalendarMonths` (1, 3, 6, 12), not 30/90/365 days. Month-end clamps (31 Jan + 1 month → 28/29 Feb).
3. Observation is the **first session on or after** the target, within 10 calendar days. Never a session before the target.
4. Performance = `(observed / sell price − 1) × 100`.
5. The cell keeps target date, observed date, observed price, percent, basis, and a status.
6. If the target is after the last session in the series: **Insufficient history**, percent null.
7. If no session falls inside the 10 days: **Unavailable**.
8. No sell date or sell price: **Not applicable**.
9. No series: **Unavailable**.
10. Corporate actions: raw map uses unadjusted `b.raw`, adjusted map uses `b.c`. If the raw/adjusted ratio changes by more than 2% between the sell session and the observation, the percent uses the adjusted ratio and the shown price is `sell price × (adj observation / adj sell)`. Basis is `adjusted`. If the only series is adjusted and it disagrees with the sell price by more than 25%, the cell is **Unavailable** rather than a guessed jump.
11. Status labels: Calculated, Unavailable, Insufficient history, AI-researched · source-backed, Not applicable. A blank is not used as a successful zero.

**AI:** `usablePathPrice()` always returns null. A model price is ignored. `listedSymbolFromResearch()` may return a ticker only when status is `researched`, `sourceUrl` is http(s), `sourceName` is present, evidence is at least 8 characters, and the evidence names a ticker that is not the asked symbol and not a stop-word (NSE, BSE, …). Path then calls `confirmSymbol(from, to)` so the alias is stored. The note says `AI-researched · source-backed. No price was stored.`

**Verified in the running sample book** (ITC sale, qty 20, sell 3 Jun 2024, sell price ₹430). Production preview DOM row:

| Window | Result | Observed | Target | Price |
|---|---|---|---|---|
| Trade P&L | +95.45% (₹4,200) | — | — | sell ₹430 |
| After sell · 1M | −4.09% | 3 Jul 2024 | 3 Jul 2024 | ₹412.42 |
| After sell · 3M | +14.07% | 3 Sep 2024 | 3 Sep 2024 | ₹490.51 |
| After sell · 6M | +5.82% | 3 Dec 2024 | 3 Dec 2024 | ₹455.03 |
| After sell · 1Y | +6.01% · adjusted | 3 Jun 2025 | 3 Jun 2025 | ₹455.83 |

Unit tests also cover a weekend target (2025-02-08 observes 2025-02-10, +10%), insufficient history when the series ends before the target, unavailable when the next session is outside 10 days (does not use the earlier session), an adjusted split, and not-applicable without a price.
